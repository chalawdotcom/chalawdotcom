### What I build

I own everything technical at **Optima IA**, an AI automation agency: the systems that turn a
B2B company's data into agents, workflows and decisions that compound. My co-founder Wassim
runs sales; I run the code.

**Creativity** is our product — the creative-strategy command center for DTC brands. It reads a
brand's Meta ads and store orders, scores and tags every creative, computes the money math
deterministically, and puts one AI strategist, *Friday*, on top: leaderboard, reports, unit
economics, briefs, and a shared market catalog of competitor shops and ads. Multi-tenant, EU-hosted,
and built on a rule I care about: **the numbers are computed in SQL, the LLMs only narrate.**

### How I work

- **Think before coding.** State the assumptions, define what "done" looks like, then build.
- **Simplicity first.** Three similar lines beat an abstraction; the minimum code that solves it.
- **Surgical changes.** Touch what the task needs and nothing beside it.
- **Measure, don't recall.** A number in a doc comes from a query, not from memory.
